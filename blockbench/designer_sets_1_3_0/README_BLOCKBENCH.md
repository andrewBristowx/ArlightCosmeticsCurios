# Fuentes de diseñador 1.3.0

Estas geometrías y animaciones se pueden importar en Blockbench como modelos Bedrock/GeckoLib.
Los nombres de huesos coinciden con `ProfessionalCosmeticModels` y `ProfessionalCosmeticAnimations`.
El render de producción usa los modelos Java para seguir exactamente los huesos del jugador; los archivos de esta carpeta son la fuente editable para futuros retoques.
Las texturas de producción están en `src/main/resources/assets/arlightcosmeticscurios/textures/cosmetics`.
